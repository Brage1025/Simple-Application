# Alex Example — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. It has no framework, dependencies, or build step.

## Run locally

Open `index.html` in a web browser. To serve the files locally instead, run a static web server from this folder, then open the local address it prints. No installation or build command is required.

The page loads DM Sans and Manrope from Google Fonts when an internet connection is available; the rest of the site is local.

## Features

- Hero introduction, About, Projects, Skills, and Contact sections.
- Responsive layouts and a sticky navigation bar with a compact mobile menu.
- Light and dark themes, with the selected theme saved in browser storage.
- Smooth section scrolling and fade-in-on-scroll animations.
- A hero tagline that cycles through three phrases with a typing effect.
- Reduced-motion support for visitors who prefer less animation.
- Three placeholder project cards with CSS-built visuals.
- A contact form with required name, email, and message validation, plus a friendly confirmation.
- Direct email link for contacting Alex.

The contact form is front-end only: it does not send or store submitted messages. Replace the placeholder project details and email address with your own before publishing.
